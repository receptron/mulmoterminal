# ローカル構成 — 必ず詰める点

- [ ] **既定ではこのパソコンからしか開けない**。サーバは `127.0.0.1` で待ち受ける。家や社内のネットワークに出すなら、ログインを必須にしてから `HOST` を変える
- [ ] **SQL は必ずプレースホルダ**（`?`）で値を渡す。文字列をつないで SQL を作らない
- [ ] **入力は API の入口で検査する**（型・長さ・必須）。画面側の検査だけに頼らない
- [ ] **状態を変える API は、同じオリジンからの呼び出しだけ受ける**（別のサイトから勝手に呼ばれないように）
- [ ] **パスワードを保存するなら、平文で保存しない**（`node:crypto` の `scrypt` で塩付きのハッシュにする）
- [ ] **データファイルのバックアップ**の手順を README に書く。`data/app.db` を消すと全部消える
- [ ] **秘密の値（パスワードの塩・セッションの鍵）を、コードに直接書かない**。`.env` に置き、`.gitignore` に入れる
