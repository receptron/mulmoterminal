# Firebase と Google Cloud にログインする

このあと作業するために、あなたの Google アカウントで2つの道具にログインします。パスワードをこの画面に書く必要はありません。

1. ターミナルで `firebase login` が動くと、ブラウザが開きます。
2. 使う Google アカウントを選び、「許可」（Allow）を押します。
3. 続けて `gcloud auth login` でもう一度ブラウザが開きます。**1 と同じアカウント**を選び、「許可」を押します。
4. ブラウザに「ログインしました」のような表示が出たら、そのタブは閉じてかまいません。

**うまくいったかの見分け方**: ターミナルに `Success! Logged in as あなたのアドレス` と出ます。

**困ったら**: 違うアカウントを選んでしまったときは、そのことをそのまま返信してください。やり直します。

終わったら「済み」と返信してください。
