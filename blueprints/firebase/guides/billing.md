# プロジェクトを従量課金（Blaze プラン）にする

サーバー側の処理（Cloud Functions）を動かすには、プロジェクトに支払い方法をつなぐ必要があります。少人数で使う規模なら、たいていは無料枠に収まります。

1. 次のページを開きます: https://console.firebase.google.com/project/{{PROJECT_ID}}/usage/details
2. 「プランを変更」（Modify plan）を押します。
3. 「Blaze」を選び、使う請求先アカウント（Cloud Billing アカウント）を選びます。まだ無ければ、画面の案内に従ってカードを登録します。
4. 予算の設定を聞かれたら、スペックで決めた金額を入れておくと安心です（あとからでも設定できます）。
5. 「購入」（Purchase）で確定します。

**うまくいったかの見分け方**: 同じページの上部に「Blaze」と表示されます。

プロジェクトが2つあるときは、もう一方でも同じことをします。終わったら「済み」と返信してください。
