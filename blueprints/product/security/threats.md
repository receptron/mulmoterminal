# 自由に作る — 必ず詰める点

- [ ] **必須の機能だけを作る**。「あとでよい」ものを最初の版に入れない（作るほど守る範囲が増える）
- [ ] **個人情報を扱うなら**、何を保存し、いつ消すかを決めて README に書く
- [ ] **公開する（不特定の人が使う）なら**、この土台（このパソコンだけで動く）では足りない。公開用の土台に移るまで、外に出さない
- [ ] **ログインなしで作るなら**、このパソコン以外から開けないことを確かめる

## 公開する（不特定の人が使う）場合

- [ ] **一人が書ける量を制限する**。投稿の長さ、回数（連投）をルールか関数で抑える。荒らし一人でデータと請求が膨らむ
- [ ] **他人のデータを書き換えられない**ことを、ルールの試験で「できないこと」側まで確かめる
- [ ] **通報と非表示**の手段を最初から持つ。管理者が不適切な投稿を消せる（関数経由）
- [ ] **ブロック**（特定の人の投稿を見ない・その人から見られない）を入れるか決める
- [ ] **公開されるプロフィールに載せるもの**を決める。メールアドレスは載せない
- [ ] **利用規約とプライバシーの説明**を、公開の前に用意する
