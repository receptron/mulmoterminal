# 社内の人だけがログインできるか試す

ログインできるべき人が入れること、入れるべきでない人が断られることの両方を確かめます。

1. ブラウザのシークレットウィンドウ（Chrome なら ⌘+Shift+N、Windows は Ctrl+Shift+N）で {{URL}} を開きます。
2. 「Google でログイン」を押し、**会社のアドレス**（`@{{DOMAIN}}`）のアカウントを選びます。アプリの画面に入れれば成功です。
3. 画面の「ログアウト」を押し、もう一度「Google でログイン」を押します。
4. 今度は**会社以外のアカウント**（個人の Gmail など）を選びます。「このアプリは @{{DOMAIN}} のアカウントだけが使えます」のような画面が出て、中に入れなければ成功です。

会社以外のアカウントを持っていないときは「試せない」と返信してください。

結果を、次のどれかで返信してください。画面に出た文言があれば、そのまま写してください。
- 両方とも期待どおり
- 会社のアカウントで入れなかった
- 会社以外のアカウントで入れてしまった
