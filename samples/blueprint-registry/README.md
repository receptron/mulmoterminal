# Sample blueprint registry (dummy)

A registry to try the blueprint market with before the official one exists. In MulmoTerminal, open
**Blueprints → Market** and add:

```
https://raw.githubusercontent.com/receptron/mulmoterminal/experiment/blueprint/samples/blueprint-registry/registry.json
```

It lists one dummy pack, `sample-hello`, cloned from this repository's `experiment/blueprint` branch.
The official registry will live in its own repository; this one is only for testing the mechanism.
