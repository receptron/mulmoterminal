# docs: 同じ home で版の違うサーバを動かす構成は対象外 (#3348)

## 問題

#3340 から、`/clear` やセル内 `/resume` で会話が移ったセッションの印（`cleared-transcripts/<id>.json`）を
reap で消さなくなった。#3340 より前の版のサーバが同じ home で動くと、その版の reap が印を消すので、
新しい版で Restart するとセルが離れたはずの会話がまた開く（#3325 の症状）。古い版のコードなので、
新しい版からは止められない。

## 決めたこと（issue の案 1）

同じ home を版の違うサーバで共有する構成は対象外とし、文書に書く。コードは変えない。

- README の「MulmoTerminal 自身の状態の置き場所」の後に、1 つの home には 1 つの版、と書く
- ガイドの FAQ（英語・日本語）に「別の版を同時に動かせるか」を足す
- 別の版を試すときは別の `HOME` で起動する（tmux のサーバと設定も別になる）、と書く
- 古い版に戻すこと自体は問題ない（その版の動きに戻るだけ）、と書く

## やらないこと

- 印の置き場所を移す・二重に書く（issue の案 2・案 3）
