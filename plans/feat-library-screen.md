# ライブラリ画面と会話（#3329、親 #3327）

デザインは `docs/library-design.md`、索引と API は #3328（`server/backends/library/`）。

## この PR でやること（一つ目）

- 経路 `/library`、`LibraryOverlay`（`FullScreenOverlay` の上）、機能メニューの入口。`/skills` と同じ配線（`useLibraryView`、`overlayOrigin`、`App.vue`、`featureMenuEntries`、`AppToolbar`）
- 骨格: 検索欄 → 分類の切り替え（この PR では「会話」だけ）→ 一覧 | 読む画面。760px 以下は一覧だけ、選ぶと読む画面、戻るは「一覧」
- 一覧: タイトル + 灰色の一行（プロジェクト · ブランチ · PR · いつ）。「今日 / 今週 / それより前」で区切る（ピン留めは二つ目の PR）。下まで読むと次のページ
- 検索: 打つと間引いてから `/api/library/search`。一致した発言の抜粋を 2 行まで。何も無いときは一文
- 読む画面: タイトル、灰色のメタ情報（金額・増減行数を含む）、本文は既存の `TranscriptPane` を `embedded` で埋め込む（見出しと固定幅を外す）
- 主操作「再開」（右下、`Enter`）: 既存の再開の経路（`cellForPanelResume` + `openCellAt`）。その会話がもう開いている・別のクライアントが持っている場合は再開せず一文で知らせる（コマンドパレットと同じ判定）
- 索引を作っている最中は、一覧の上に進捗を一行（骨組み表示）
- キー: `/` で検索欄、上下で移動、`Enter` で再開、`Esc` で閉じる
- 英日ほか 5 言語、明暗、スマホ幅

## 二つ目の PR（ピン留めと名前）

- ピン留めと名前は `~/.mulmoterminal/library/marks.json` に記録する。索引（消して作り直せる写し）には入れない。会話のファイルにも書かない
- ピン留めした会話は一覧の先頭の「ピン留め」にまとめ、時刻の区切りからは外す。名前は一覧・読む画面・検索結果のタイトルに出す（検索は名前では引けない）
- 読む画面の `more_horiz` に「ピン留め / 外す」「名前を変える」。名前はその場で書き換え、`Enter` で保存、`Esc` でやめる（ライブラリは閉じない）
- 壊れた `marks.json` は空として読まない。空として読むと、次の変更でユーザーの記録を消してしまうため

## 三つ目の PR（History メニューからの入口）

- Claude のセッションを持つセルの History メニューの末尾に、区切り線の下で「ライブラリで開く」（`local_library`）。右の欄を開く項目ではないので、チェックは付かない
- ライブラリは `/library?session=<id>` で開き、その会話を選んだ状態にする。一覧の読み込み済みのページに無ければ id で読みに行く（古い会話でも開ける）
- 開いたままのライブラリに別のセルから来たときも、その会話へ移る
- URL にはセルのディレクトリも載せる（`cwd`）。同じセッション ID が二つのプロジェクトにあるとき（写した会話）、そのセルの方を選ぶ。無ければいちばん新しいもの
- 後から来た依頼が勝つ。先の依頼の読み込みが遅れて返っても選び直さない

## 見送り: 「ここから分岐」

`claude --fork-session` はある（`--resume` と一緒に使うと、新しいセッション ID で続く）。ただ、セルとサーバーのセッション追跡は再開した ID を前提にしているので、分岐で ID が変わるのは別の設計が要る。このタスクでは入れず、必要になったら別の issue にする。

## 決めたこと

- 分類の切り替えは「会話」だけを出す。まだ無い分類を押せない形で並べると、押せないものが主役になる
- 再開の判定はコマンドパレットの `busy` を共有する（同じ規則を二か所に書かない）
- 本文の表示は `TranscriptPane` を使い回す。読む画面専用に作り直さない
