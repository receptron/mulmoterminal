# スキルの評価の前の結果を開いて、版ごとの推移を見られるようにする（#3469）

## 目的

スキルを直し続けるには、前の結果と今を比べられる必要がある。前の結果は日時・判定・状態の1行だけで、中身は開けなかった。

## 決めたこと

1. 前の結果は `src/components/SkillEvalHistory.vue` に分ける。各行に、測定ならスキルありとなしの合格率と判定、モデル探しなら足りたモデルを出す。並べると版ごとの推移になる
2. 行を開くと、今の結果と同じ部品（`SkillEvalResult` / `SkillEvalLadder`）でその実行の結果を出す
3. 概要（`GET /api/skill-evals`）に、今の `SKILL.md` のハッシュ `skillHash` を足す。各実行が記録しているハッシュと比べ、今と違う文を測った行に印を付ける。改善案の実行は自分の文を測っているので、印は付けない（違うのが当たり前なので）。今の文が読めないときは、どの行にも付けない
4. グラフは作らない。課題が少なく、実行の数も一覧に出る分だけなので、数字の並びで足りる
