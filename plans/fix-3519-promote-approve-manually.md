# fix #3519: ライブラリの昇格は手で承認するよう案内する

昇格・繰り返し・整理のセルは plan mode で開き、承認の初めの選択肢は auto mode。書き先（記憶のフォルダ、`~/.claude/skills/`、全体の `CLAUDE.md`、バックアップ）は作業ディレクトリの外で、auto mode では一回ごとに判定に回り、断られることがある。

#3512 と同じ直し方（`--allowedTools` の許可の規則）は、`~/.claude` の下には効かないと測って分かった（#3519 のコメント）。サーバーが書く道具を足す案は範囲が大きいので見送り、ユーザーの選んだ案内だけにする。
