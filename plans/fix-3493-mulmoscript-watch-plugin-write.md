# fix #3493: mulmoScriptWatch.spec のプラグイン書き込みを本物と同じ形にする

spec はプラグイン自身の保存を `fs.writeFileSync`（その場で空にしてから書く）で真似ていた。poll がその間に入ると空のファイルの stamp を見て、`recordOwnWrite` が記録する書き終わりの stamp と一致せず、自分の書き込みが外からの変更として知らされる。本物のプラグインの保存はどれも一時ファイルから rename で置き換えるので、poll は書きかけを見ない。

## 変更

- spec に `pluginWrite(file, content)`（一時ファイルに書いて `renameSync`）を足し、プラグインの保存を真似る 4 か所をそれに置き換える。外からの編集はその場書きのまま。本体は変えない。

## 確認

- 空にした状態を poll に見せてから書き終える一時的な spec で、CI と同じ失敗が毎回出ることを確かめた。
- 修正後の spec を繰り返し実行して緑。
- 本体の待ちのあとの確かめ直し（`isEchoOfOwnWrite` の二度目）を外すと、該当のテストが赤になることを確かめた。
