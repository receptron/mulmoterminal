# #1961 — ブラウザ既定のボタン色が透けている

## 症状

ツールバー右端の Update ピルが nord / midnight で読めない。ホバーすると読める。

## 原因

`src/tailwind.css` は preflight を意図的に外していて（同ファイル冒頭に理由あり）、
`src/style.css` の `@layer base` にも `button` の背景を戻す規則が無い。結果、**通常時に
背景を指定していない `<button>` はブラウザ既定のボタン色（`ButtonFace`）で塗られる**。
ダークテーマではそれが明るい塗りになるので、accent の文字が乗ると読めない。

## 実測（Chromium・実アプリ・この PR の前）

Update ピルの算出値。背景はどのテーマでも `rgb(239,239,239)` で、テーマのトークンではない:

| テーマ | 文字 | 背景 | コントラスト |
| --- | --- | --- | --- |
| nord | `rgb(136,192,208)` | `rgb(239,239,239)` | **1.74:1** |
| midnight | `rgb(74,140,255)` | `rgb(239,239,239)` | **2.82:1** |
| solarized | `rgb(38,139,210)` | `rgb(239,239,239)` | **3.20:1** |
| daylight | `rgb(37,99,235)` | `rgb(239,239,239)` | 4.49:1 |

issue の Chrome 列（nord 1.74 / midnight 2.82）と一致。**light テーマも無傷ではなく、
solarized は WCAG AA（4.5:1）を割っている** — issue は「読める」としていたが、測ると落ちている。

## site ではなく class として直す

同じ形のボタンが他にもある。実ブラウザで測って確認できたのは 2 つ目の実例:
**Update ドロップダウンを開くと、その中の Copy ボタンが `rgb(239,239,239)`** になる
（ピル自身は開いている間 `bg-selected` を得るのでリストから消える）。同じ機能の中に 2 件ある
ので、1 箇所直しても次のボタンが同じ穴を掘る。

静的には issue が 17 箇所を挙げているが、`:class` で背景が付くものが混ざっている。読んで
選り分けた結果、通常時に背景を持たないのは `AppToolbar`(Update ピル / Copy)、
`CockpitRowMenu`(並べ替えハンドル + メニュー項目 2 つ)、`CopyCodeBlock`(Close) など。
`FilterChip` / `SettingsButton` / `QuestionPane` は両分岐で背景を指定しているので無関係。

## 直し方

`src/style.css` の `@layer base` に 1 本入れる:

```css
button {
  background-color: transparent;
}
```

**blast radius は構造的に「今ブラウザ既定色で塗られているボタン」だけ**になる。utility は
`@layer utilities`（最後）なので base に勝ち、component の `<style scoped>` は無レイヤーなので
やはり勝ち、`.cell-btn` のようなクラス規則は同レイヤーでも詳細度で勝つ。つまり**作者が背景を
指定しているボタンは 1 つも変わらない**。

これは推論なので、**変更前後で全ボタンの算出背景を差分計測して確かめる**（下記）。

## 検証

- **差分計測**: 4 テーマ × 2 画面で全 `<button>` の算出背景をスナップショットし、変更前後で
  比較する。**変わったのが「変更前に `rgb(239,239,239)` だったボタンだけ」であること**を確認する。
- Update ピルのコントラストが 4 テーマすべてで AA を満たすこと。透明にすると背後の塗りが効くので、
  **祖先をたどって実際に塗られている色**で測る。
- `yarn format` → `lint` → `typecheck` → `build` → `test`。
- jsdom では UA 既定色が出ないので、**この回帰は unit テストでは捕まえられない**。CI に入るのは
  「規則が style.css に在ること」までで、実測は手元の実ブラウザで行う。
