# docs #3503: スキルの評価を 1 枚のガイドページにする

`features.md` の Skills viewer の行に詰め込まれていた評価の説明を、手順のページ `docs/guide/{en,ja}/skill-eval.md` にする。

## 構成

必要なもの → 1 スキルを開く → 2 課題を作る → 3 測る → 4 結果を読む → 5 改善案を作って測る → 6 採用する → 7 安いモデルを探す → 8 あとで見返す → 費用 → うまくいかないとき → 置き場所。

## 例

`product-article-ja`（ユーザーのスキル）の実際の評価（測定、改善案、モデル探し）を vite（6856）の今の画面から撮った。課題を作る段だけは、別のスキル `nazonazo` のセルの写真（`product-article-ja` の課題は別の所で作られていたため）。採用はしていない（スキルが dotfiles にあるため）。改善案の差分の画面は、モデル探しのあとは欄に出ないので写真が無い。

## ほか

- `features.md` の行は要約とリンクにした。index の Feature reference の下にリンク。
- 課題を作るセルで auto mode を選ぶと保存できない件は #3507。ページの手順では 2 番を選ぶよう書き、困ったときの表にも入れた。
