# スキルの一覧に評価の判定を出し、手をつけるものに絞れるようにする（#3467）

## 目的

評価の結果はスキルを1つずつ開かないと見えず、スキルが多いとどれから手をつければよいか分からない。

## 決めたこと

1. 印はサーバーが評価のフォルダから読む（`GET /api/skill-evals/marks`、`server/backends/skillEval/evalMarks.ts`）。カタログ側からは引かない。プラグインだけで千個のスキルがあり得て、印があるのはフォルダのある数個だけだから
2. フォルダからスキルへのたどり方:
   - スキルの名前は `cases.json` の `skill` から取る。フォルダ名では `:` が `__` になり、元に戻せないため
   - プロジェクトのスキルのフォルダ名には、そのディレクトリのハッシュが付いている。ターミナルを開いたことのあるディレクトリと照らし、合うものがなければ飛ばす
   - その名前とディレクトリから作ったフォルダの場所が、読んでいるフォルダと違えば飛ばす（ほかのスキルの印を付けないため）
   - 課題の組が読めない、または SKILL.md がもうないときも飛ばす
3. 印は、今の SKILL.md と課題の組を測った完了済みの測定（`isBaselineFor`、評価の欄が改善の起点に使うのと同じもの）の判定。その測定がなければ「未測定」
4. 「手をつけるもの」の切り替えで、印が逆効果・差なし・未測定のもの、または印がなく会話で使われているものだけに絞る。印が読めなかったときは、印も切り替えも出さない
5. 印は一覧を開いたときと、改善案を採用したときに読み直す
