# ライブラリ 7-3: 記憶の整理案（#3334 の三つ目）

親: #3327。#3334 の一つ目（昇格、#3366）、二つ目（繰り返し、#3393）の続き。

## 決めたこと（2026-11-21）

- 入口: ライブラリの「記憶」で、プロジェクトごとの見出しにボタン（このプロジェクトの記憶の整理案を頼む）。対象はそのプロジェクトの記憶だけ
- スキルに提案させるもの: 重複した記憶の統合（`[[リンク]]` も残す側へ）、古い・もう当てはまらない記憶の削除（コードを読んで確かめたうえで）、健康診断で出た問題の修正、規則やスキルへの移し替え
- 消し方: 書き換える・消すファイルは先に `~/.mulmoterminal/library/backups/` に控えを取り、戻し方を伝える。スキルだけで完結する
- 昇格・繰り返しと同じく、プランモードのセルで同梱スキル `mulmoterminal-library`（`tidy <フォルダ名>`）が案を作り、プランを承認するまで何も書かない

## 作り

- `POST /api/library/memory/:slug/tidy`（`server/routes/library-memory-tidy-routes.ts`）: 同じオリジンのみ。フォルダ名を確かめ（400）、記憶のフォルダがあること（404）、索引にあるそのプロジェクトのディレクトリがこの機械にあること（409）を確かめて、昇格と同じ起動（プランモード）で始める。送る文はサーバーが作る（`tidyTurn`）
- フォルダ名の判定 `isProjectSlug` は、サーバーとスキルへの文の両方で使うので `common/libraryMemory.ts` へそのまま移した
- 画面: `LibraryMemoryTidy.vue`（見出しのボタンと、断られたときの一文）
