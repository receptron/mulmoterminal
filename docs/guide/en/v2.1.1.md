# What changed in 2.1.1
{: .no_toc }

**As of 2026-07-27.** This page is a snapshot taken at release. For anything that changes
later, follow the links to the living guide.

- TOC
{:toc}

---

## Nothing to configure

2.1.1 is a follow-up to 2.1.0's grid-first startup: one visible change to the toolbar, and two
fixes to how the header and the full-screen panels behave. **No new settings, no config to
write, no migration** — upgrading is all there is to do.

---

## The toolbar now differs between the two views

The header used to carry the same buttons everywhere. Since 2.1.0 opens on the grid, that
meant the screen for **supervising agents** led with buttons for **reading content**.

| | Grid | Single view |
|---|---|---|
| Running agents | New terminal, cell ordering, the status tally | — |
| Reference while supervising | **Pull requests**, **Worklog** | — |
| Content | — | **Collections**, **Accounting**, **Wiki**, your pinned favourites |
| Switching views | chat / grid icons | chat / grid icons |

**Where did Collections / Wiki / Accounting go?** They are in the **single view** — click the
**chat** icon (or open `/chat`). Nothing was removed; the buttons moved to the screen those
surfaces belong to.

**Worklog moved** from the right-hand end of the header into the grid's own row, next to Pull
requests. It still opens the wiki filtered to `#worklog`.

→ Reference: [Basics](basics.html)

## Closing a full-screen panel returns you where you opened it

Collections, Wiki, Pull requests, Accounting and Files each cover the screen below the header.
Closing one used to drop you in the single view no matter where you came from — so opening
Pull requests from the grid and closing it moved you off the grid.

They now return to the view you opened them from. Opening one from the grid also **keeps the
grid's buttons in the header** while the panel is up, so the button you just clicked is still
there (and still highlighted) rather than vanishing.

Two details worth knowing:

- Reaching a panel by a **direct URL or browser history** — where there is no "where you came
  from" — still lands you in the single view when you close it.
- Hopping straight from one panel to another (Pull requests → Worklog) keeps the **original**
  view as the return target, not the panel you just left.

---

## How to tell you have it

Open the grid, click **Pull requests**, and look at the header: the Pull requests button should
still be there and highlighted, with **New terminal** and the ordering toggle beside it. Close
the panel and you should be back on the grid.
