# 9.7.0 — See when a token at its limit resets, and JingleScript reads scores from files

**A snapshot as of 9.7.0 (released 2026-10-10).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

## New features

### The Token usage screen says when an at-limit token resets

This applies only if you use [token rotation](token-rotation.html). Open **More features -> Token usage**. A token
that has hit its usage limit used to read only "At its usage limit — skipped until it resets", with no hint of
when. It now adds a line per window
([#2977](https://github.com/receptron/mulmoterminal/pull/2977)):

- `5-hour window: resets around 10/10 18:00 (as last read)`
- `Weekly window: resets around 10/12 15:00 (as last read)`

The date and time are written for your interface language. They are the reset times each window **last reported**,
so they are only as fresh as the last time that token answered. A window whose time has already passed is left out.
Both windows are listed because Claude Code does not say which one blocked the token. A token that was never measured
shows the plain sentence, as before.

### JingleScript reads a score from a file

You can now tell an agent to check or render a JingleScript score kept in a `.json` file, instead of pasting the whole
score into the request
([#2979](https://github.com/receptron/mulmoterminal/pull/2979)). Give it a path; a relative path means a file in that
session's own folder. Only `.json` files are read. The player also gets a **Download MIDI** link. Nothing to configure.

## What looks different

- **An at-limit row on the Token usage screen has the reset lines described above.**
- **The JingleScript player has a Download MIDI link.**

## Under the hood

- **`mulmocast` is now 2.19.0.** MulmoCast scripts can use `beat.soundEffects` to place sound effects inside a beat,
  and a sound effect's source can be a JingleScript score. The default Gemini video model becomes
  `gemini-omni-1.1-flash`, because the Veo 3.1 previews shut down on 2026-10-22; a script that names one gets an error
  that points at the replacement
  ([#2979](https://github.com/receptron/mulmoterminal/pull/2979)).
- **Packages were updated**, including the icon font `material-symbols`
  ([#2978](https://github.com/receptron/mulmoterminal/pull/2978), [#2980](https://github.com/receptron/mulmoterminal/pull/2980), [#2982](https://github.com/receptron/mulmoterminal/pull/2982)). Icons look the same.
- **The guide was tidied**: a new opening page, pages brought in line with the app, and a fixed table
  ([#2965](https://github.com/receptron/mulmoterminal/pull/2965), [#2967](https://github.com/receptron/mulmoterminal/pull/2967), [#2969](https://github.com/receptron/mulmoterminal/pull/2969), [#2971](https://github.com/receptron/mulmoterminal/pull/2971), [#2972](https://github.com/receptron/mulmoterminal/pull/2972), [#2973](https://github.com/receptron/mulmoterminal/pull/2973), [#2974](https://github.com/receptron/mulmoterminal/pull/2974)).

More: [Token rotation](token-rotation.html), [Feature list](feature-list.html).

**How to tell you have it:** with token rotation on and a token at its limit, More features -> Token usage shows
"resets around ..." lines under the limit sentence.
