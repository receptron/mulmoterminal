# 9.8.0 — A help desk, and Ctrl+B reaches your agent

**A snapshot as of 9.8.0 (released 2026-10-10).** It will go stale as the app moves on — that is
expected, and the living reference is the guide each section links to.

## New features

### Ask the help desk about MulmoTerminal

A **help icon** now sits in the toolbar, next to the gear
([#2987](https://github.com/receptron/mulmoterminal/pull/2987)). Press it and a new terminal opens in your workspace
with a help agent already running. Ask in your own language: what MulmoTerminal can do, how a part of the screen
works, how to set something up, or what is new in the version you are running and in the latest one.

- It answers from the guide, the changelog and the source **that shipped with the version you have**, and says where
  it checked each fact, so it does not describe a feature your version lacks.
- It only reads. It changes nothing, which is why it starts without asking you first. If you ask it to change a setting
  or report a bug, it points you to the right helper instead.
- **Settings -> Help** has the same button under the guide links.
- It always opens in the workspace, whichever project or collection is on screen, because the question is about the
  app, not about that project.

Nothing to configure.

### Ctrl+B reaches your agent: the tmux prefix is off

Each cell runs inside a dedicated tmux so the session survives a restart. tmux listens for a **prefix key**, by
default **Ctrl+B**, and treats the key after it as a tmux command. But Ctrl+B also means "one character left" in the
shell, in Claude Code's input box and in the macOS text system. In a cell, the first Ctrl+B looked ignored and the next
key you pressed (`c`, `%`, `d`) ran a tmux command instead of reaching your agent
([#2985](https://github.com/receptron/mulmoterminal/pull/2985)).

MulmoTerminal never uses that prefix, so it is now **off by default**: every key goes to the agent. Nothing to do.

If you attach to the sessions yourself (`tmux -L mulmoterminal attach`) and want tmux's keyboard commands such as
`Ctrl+B d` to detach, turn a prefix back on:

1. Open **Settings -> Terminal keys**, find **tmux prefix key**, and pick `Ctrl+B` (tmux's own default) or `Ctrl+]`.
2. Or write it in `~/.mulmoterminal/config.json`: `{ "tmuxPrefix": "C-b" }`. Other Control keys work too (`C-a`
   to `C-z`, `C-Space`, `C-]`, `C-_`, `C-^`, `C-@`); anything else falls back to off.
3. It applies at once, also to the tmux server that is already running. No restart.

The mouse wheel still scrolls the terminal's history either way. More: [Configuration](config.html#tmux-prefix).

## What looks different

- **A help icon in the toolbar**, and a Help button in Settings.
- **Settings -> Terminal keys has a new "tmux prefix key" dropdown.**
- **The Files pane header wraps** when the pane is narrow, so its Close button stays inside the pane
  ([#2988](https://github.com/receptron/mulmoterminal/pull/2988)). Before, with a Markdown file open at a narrow split,
  the last buttons, Close among them, sat past the window's edge. Nothing is hidden or moved; the buttons just
  continue on a second line.
- **A session opened with the Files pane open starts at the right width.** It used to come up at the width the
  terminal had beside the pane, until something resized it
  ([#2989](https://github.com/receptron/mulmoterminal/pull/2989)).

## Under the hood

- **The npm package now ships the whole guide**, the changelog and `docs/facts.json`, so the help desk works offline
  and matches the version installed ([#2987](https://github.com/receptron/mulmoterminal/pull/2987)). The package is
  a few megabytes larger.
- **The live tmux server follows your setting.** A saved prefix is applied to a server that outlived the app, the
  config file it reads is written atomically, and a prefix binding left by an earlier run is removed
  ([#2985](https://github.com/receptron/mulmoterminal/pull/2985)).

More: [Configuration](config.html), [Feature list](feature-list.html).

**How to tell you have it:** the toolbar has a help icon next to the gear, and pressing Ctrl+B in a cell moves the
cursor one character left on the first press.
