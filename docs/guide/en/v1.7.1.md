# 1.7.1: grid session list and wheel scrolling
{: .no_toc }

**As of 2026-07-24.** **Nothing to configure.** Both are regressions introduced in 1.7.0.

---

## What was fixed

- **The grid's resume picker lists every session again.** 1.7.0 filtered it to grid-launched sessions, so anything started in a normal terminal or a plain `claude` **disappeared from the grid**.
- **The wheel scrolls the terminal.** In a zoomed terminal it was **cycling the input history** instead. Wheel scrolls; keyboard ↑/↓ still cycles history.
- **A corrupt `config.json` no longer wipes every setting** on the next save. (Hardened further in 1.12.0.)
- **Clipboard copy through tmux** works again.
