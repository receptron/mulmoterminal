# 13.0.0 — Node 24.15 と、静かになる音声入力

**13.0.0 時点（2026-11-18 リリース）のスナップショットです。** アプリが変わるにつれて古くなります。
それは想定どおりで、最新の説明は各節からリンクしているガイドにあります。

**更新する前に: この版は Node.js 24.15 以上が必要です。** `node -v` で確かめてください。`v22…` や、
`v24.15.0` より古い `v24` が出たら、先に Node の最新の LTS 版を入れてください
（[はじめに・ステップ 1](getting-started.html#step1)）。古い Node のままだと、`npx mulmoterminal` は
「Node が古い」というメッセージと更新手順を出して止まります。

更新:

```bash
npx mulmoterminal@latest
```

## 新機能

### 音声入力で、無音や雑音を飛ばせるようになりました

音声入力は、ブラウザが「声が大きい」と判断した区間をすべて文字起こしに送るので、周りの雑音も届きます。
Whisper は無音や雑音を渡されると、学習でよく見た「ご視聴ありがとうございました」のような定番の文を
プロンプトに書いてしまいます（[#3296](https://github.com/receptron/mulmoterminal/issues/3296)）。

音声入力が使う `whisper-server` に、環境変数 `WHISPER_SERVER_EXTRA_ARGS` で指定を足せるようになりました
（[#3321](https://github.com/receptron/mulmoterminal/pull/3321)）。whisper.cpp の発話判定を有効にすると、
声の無い部分が飛ばされます。

**試し方**（音声入力が動く macOS で）:

1. お使いの `whisper-server` が発話判定に対応しているか確かめます。1 行出れば対応しています:
   ```bash
   whisper-server --help 2>&1 | grep -- --vad
   ```
2. Silero の発話判定モデルを [ggml-org/whisper-vad](https://huggingface.co/ggml-org/whisper-vad) から入手します。
3. MulmoTerminal を起動するシェル、または横の `.env` に設定して、MulmoTerminal を起動し直します:
   ```bash
   export WHISPER_SERVER_EXTRA_ARGS='--vad --vad-model /path/to/ggml-silero-v6.2.0.bin'
   ```

- 空白を含むパスは JSON の配列で書きます: `'["--vad", "--vad-model", "/path with space/x.bin"]'`
- モデル無しでも、`--no-speech-thold 0.4` が効きます（既定は `0.6`）。
- `--model`・`--host`・`--port` など MulmoTerminal が自分で渡す指定は受け付けません。サーバのログに
  `WHISPER_SERVER_EXTRA_ARGS ignored` と出て、音声入力はこれまでどおり動きます。
- `whisper-server` が受け付けない指定を書くと、起動しなくなることがあります。音声入力が使えなく
  なったら、環境変数を消して起動し直してください。

環境変数を設定しなければ、何も変わりません。詳しく:
[よくある質問 — 話していないのに、音声入力が入力します](faq.html#voice-hallucination)

## 画面の変化

画面には変化がありません。目に見える違いは起動時だけです。Node が 24.15 より古いと、
`npx mulmoterminal` は起動する代わりに「Node が古い」というメッセージを出して止まります
（[#3321](https://github.com/receptron/mulmoterminal/pull/3321)）。

## 見えない変化

### Node.js 24.15 以上が必要になりました

MulmoTerminal はサーバの中核部分を MulmoClaude と共有しています。その中核が Firebase 13 を使うように
なり、Firebase 13 は Node 24.12 以上を必要とします。MulmoTerminal は MulmoClaude に合わせて 24.15 に
しました（[#3321](https://github.com/receptron/mulmoterminal/pull/3321)）。版が 13.0.0 なのはこのためで、
Node 22 のままの方は、MulmoTerminal より先に Node を更新する必要があります。
[サーバを別のマシンで動かす](remote.html) の Docker の例も `node:24` からに変わりました。

### 依存パッケージ

共有している MulmoClaude のパッケージが、その中核に合わせて新しい major に上がりました。スマホ連携と
共有アプリが使う Firebase は 13.4.0 になります。することは何もありません。更新後にスマホ連携の
Google ログインがおかしければ、知らせてください。ほかに通常の小さな更新も入っています
（[#3319](https://github.com/receptron/mulmoterminal/pull/3319)）。

**この版になっているかの確かめ方:** Node 24.15 以上で `npx mulmoterminal@latest` が起動します。
`WHISPER_SERVER_EXTRA_ARGS` を設定していれば、起動時にサーバのログに `WHISPER_SERVER_EXTRA_ARGS applied`
と出ます。
