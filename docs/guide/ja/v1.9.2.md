# 1.9.2：Windows の npm-global インストールでも起動
{: .no_toc }

**2026-07-25 時点**のスナップショットです。

**設定は不要です。** Windows 以外の方には影響がありません。

---

## 直ったこと

1.9.1 は公式インストーラ版（`claude.exe`）を直しました。こちらは**もう一方**、`npm i -g` で入れた場合です。この形式では `claude`（シェルシム）・`claude.cmd`・`claude.ps1` しか置かれず、**`.exe` が存在しません**。

node-pty が最終的に呼ぶ `CreateProcessW` は **PE イメージしか実行できない**ので、`.cmd` も拡張子なしのシムも起動できませんでした。バッチが対象のときは `cmd.exe /d /s /c` 経由で起動するようになり、`claude` / `codex` / `tmux` / ランチャーすべてが同時に対応します。

`CLAUDE_BIN` に `.cmd` のパスを明示する回避策も、同じく包まれます。

## 確認方法

Windows でセッションを起動できれば直っています。1.11.1 も併せて必要な場合があります（`--settings` のクォート問題）。
