# 1.7.1：グリッドのセッション一覧とホイールスクロールの回帰修正
{: .no_toc }

**2026-07-24 時点**のスナップショットです。

**設定は不要です。** どちらも 1.7.0 で入った回帰の修正です。

---

## 直ったこと

- **グリッドの再開ピッカーに全セッションが戻りました** — 1.7.0 でグリッド起動のセッションだけに絞ってしまい、通常のターミナルや素の `claude` で始めたセッションが**グリッドから消えて**いました。そのディレクトリの全セッションが再び並びます。
- **ホイールでターミナルがスクロールします** — 拡大したターミナルでホイールを回すと、**入力履歴が回って**いました。ホイールはスクロール、キーボードの ↑↓ が履歴、という本来の割り当てに戻りました。
- **設定ファイルが壊れても全設定が消えなくなりました** — `config.json` が壊れていると、次の保存で既存の設定を捨てていました。（この件は 1.12.0 でさらに補強されています。）
- **tmux 経由のクリップボードコピー**が動くようになりました。
