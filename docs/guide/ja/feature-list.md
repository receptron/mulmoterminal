# 全機能リスト
{: .no_toc }

9.1.0 時点で MulmoTerminal にある機能を、領域ごとに一行ずつ並べた一覧です。行末の `(vX.Y.Z)` はその機能が最初に入った版で、その後の大きな拡張は行の中に版番号で添えています。不具合の修正や内部の変更は載せていません。それらは [ChangeLog](https://github.com/receptron/mulmoterminal/blob/main/docs/ChangeLog.md) を、詳しい使い方は[機能リファレンス](features.html)と各節の「詳しく」から辿れるページを見てください。

## グリッドとセル

詳しく: [基本編](basics.html)

- 起動のディレクトリを `~` から書ける (v8.5.0)
- 最近閉じたセルをコマンドパレットの「Reopen: …」から今のターミナルの隣に開き直す。エージェントは会話を再開する。キー割り当て `terminal-reopen` で最新の一つを開く (v8.2.0)
- 並び順ボタンから Auto / Manual / Priority を選べる (v6.6.0)
- ペインのボタンは「History」（プロンプト・会話・タイムライン）と「Tools」（ツール・Canvas・コレクション）の2つのメニュー (v6.6.0)
- ツールバーは Rooms・Blueprints・Worklog を説明付きの1つのメニューにまとめ、未設定のものは隠す (v6.6.0)
- ロスターの各行と（6.6 で）フィルムストリップに ⋮ メニュー: 未読・既読、移動、脇に置く、閉じる (v6.5.0)
- tmux のコピーモード中のセルに「Viewing history」と「Back to input」ボタンを出す (v5.7.0)
- 新しいターミナルの起動フォームはどの画面でも右端に重ねて開く（7.2 でヘッダー2段目の + からも） (v4.12.0)
- 再開一覧で、誰もつないでいない実行中の会話に印を付け、停止ボタンを出す (v4.6.0)
- セルごとに右ペインを持ち、拡大対象を移ると、そのセルのペインが出る (v4.4.0)
- ヘッダーのパスがメニューになる: フォルダを開く、ファイルを見る、新しいターミナル、この設定（6.6 で全セルに） (v4.4.0)
- 起動フォームの先頭チップは常にワークスペースで、そこで始めたセッションには WORKSPACE と表示する (v4.3.0)
- ツールチップはホバーしてすぐ出る（6.6 ですべてのアイコンに） (v4.1.0)
- スマホや予約タスクなど、タブを開かずにサーバーが始めたセッションもグリッドのセルになる (v4.0.0)
- 全画面の画面はグリッドの上に重ねて開き、閉じると元の画面に戻る (v4.0.0)
- セルを「脇に置く」と、タイル・フィルムストリップ・ロスターで薄く表示される (v3.0.0)
- ロスター・サイドバー・タブバーでも、入力待ちは琥珀、未読の完了は緑で示す (v2.9.0)
- 空のセルの起動行に「Shell」があり、設定なしで OS の既定シェルを開ける (v2.8.0)
- セルのヘッダーの鉛筆で、セッションごとに自分用の1行メモを付けられる（ロスターとスマホにも出る） (v2.7.0)
- 拡大セルの区切り線をドラッグやキーで動かせ、幅は再読み込み後も残る (v2.7.0)
- ファイルをターミナルにドロップすると保存してパスを挿入する（2.8 で画像の貼り付けも） (v2.7.0)
- 裏で動く作業用セッション（予約タスク・起動されたもの）は「Background」に分けて表示し、途中で止まったものは failed と出す (v2.7.0)
- ヘッダーのボタンで、最新の返答の最後のコードブロックを字下げなしでコピーする (v2.5.1)
- 起動フォームでディレクトリを選ぶとそこで再開できる会話が並ぶ（4.6 で選んだエージェントの履歴に） (v1.1.0)
- 起動フォームの作業ディレクトリを OS のフォルダ選択ダイアログで選べる（Windows、WSL2、Linux 各種にも対応） (v0.9.2)
- コックピット・ロスター: 拡大中のターミナルの横に全セッションを1行ずつ要約（1.7 で並べ替え、5.2 でドラッグ） (v0.9.1)
- AI が要約したセッション名をセルのヘッダーとセッション一覧に出す (v0.9.0)
- セルのヘッダーをクリックで拡大し、残りはフィルムストリップ（サムネイル列）に並ぶ (v0.8.0)
- コマンド実行セルの出力を AI が要約・説明し、プロンプトとしてコピーできる (v0.8.0)
- 起動フォームのチップにディレクトリの色の帯と、実行中であることの表示が付く（2.4、2.8 で拡張） (v0.8.0)
- 設定したプログラム（シェル・codex など）をセルで常駐ターミナルとして起動できる (v0.6.2)
- セルを入力待ち（琥珀）・完了（緑）・作業中（青）・アイドルで色分けして並べる（1.4 で作業中を計画中と実装中に分ける） (v0.6.1)
- ツールバーが全ページの入力待ち・完了・作業中のセル数を数えて出す (v0.6.1)
- ビューを切り替えてもターミナルは動き続け、戻ると再接続する（1.8 で約1000行の履歴も戻る） (v0.6.0)
- タブの favicon がセッションの状態（作業中・要対応・アイドル）を表す (v0.6.0)
- 起動したディレクトリを覚え、次回の起動フォームにチップとして並べる (v0.6.0)
- ターミナルが動いている間にタブを閉じる・再読み込みすると確認が出る (v0.6.0)

## エージェント

詳しく: [エージェント](agents.html)

- Skills 画面の skills.sh の切り替えで、まだ入っていないスキルを公開一覧から検索し、`SKILL.md`・持ち込むファイル・コードを実行できるファイルを見られる。インストールはせず、`npx skills add` の行をコピーできる (v8.4.0)
- その他の機能 → Skills で、`~/.claude/skills`・有効なプラグイン（`plugin:skill` の名前で）・ターミナルを開いたフォルダの `.claude/skills` にあるスキルを 3 列で一覧・検索。自分のスキルを上書きするフォルダのスキルに印がつく (v8.3.0)
- 設定の「Models and backends」でカスタムエージェント・アカウント・バックエンドを追加・削除できる（URL とキーを検証） (v7.2.0)
- Claude Code が古くて自動許可モードが使えないとき、その旨と更新方法をセルに出す (v6.6.0)
- Codex が承認を待つ間、セルを「Needs input」にして音とプッシュ通知を出す (v6.2.0)
- ベータ: 別の Claude Code / Codex の契約（アカウント）でセルを動かし、起動フォームで選ぶ (v5.8.0)
- ベータ: トークンのローテーション。新しい Claude のセッションを、複数の契約のうち週の枠の残りがリセットまでの時間あたり最も多いもので始め、会話は契約をまたいで続く (v9.2.0)
- 98% に達したり上限に当たったりしたセッションは、同じ会話のまま別の契約へ移る (v9.2.0)
- セルの見出しに動いている契約の名前が出て、「その他の機能」→「トークンの使用量」で契約ごとの 5 時間枠・週の枠の残りを一覧できる (v9.2.0)
- 上限で外れたトークンの行に、各枠が最後に報告したリセット予定の日時が出る (v9.7.0)
- その名前をクリックすると、ほかの契約が週の枠の残りとリセットまでの時間つきで並び、選ぶと同じ会話のままその契約でセッションを再起動する (v9.6.0)
- 入っていないエージェントは Agent Picker で薄く表示し、理由と導入手順へのリンクを出す (v5.8.0)
- --agent や defaultAgent で既定のエージェントを決められ、Claude Code が無くても起動する (v4.25.0)
- GitHub Copilot CLI をセルで動かせる（Agent Picker、GUI ツール、作業中の表示） (v4.22.0)
- Cursor CLI をセルで動かせる（状態表示と音、4.23 で GUI ツール） (v4.22.0)
- セル・ディレクトリ・会話をそのままにエージェントだけを再起動できる（6.6 で Tools メニューにも） (v4.14.0)
- Agent Picker とロスターでエージェントごとに専用のマークを出す (v4.7.1)
- Muse を Agent Picker から選べる（再開、ヘッダーのバッジ） (v4.7.0)
- Grok を Agent Picker から選べる (v4.5.0)
- customAgents で自分の Claude Code 起動コマンドを Agent Picker に足せる（再開とコスト表示は残る） (v4.5.0)
- claude.ai のコネクタと自分の MCP サーバーがワークスペースのセルでも使える (v4.4.0)
- Antigravity（agy）を3つ目のエージェントとして使える（再開、GUI パネル、2.9 でサーバー再起動後の再開） (v2.8.0)
- claude-ollama で Claude Code をローカルの Ollama モデルで動かす (v1.6.0)
- セッションを始めるときにプロバイダーとモデルを選べる (v1.6.0)
- Codex を Claude Code と同じ扱いで動かせる（再開、状態表示、4.5 でサーバー再起動後の再開） (v0.7.0)

## 会話・質問・セル同士

詳しく: [会話](conversation.html)

- スマホのセッション一覧に、各セルが取り組んでいる issue と PR を出す (v2.5.3)
- 通知音は完了と入力待ちで変えられ、それぞれ切り替えとプリセットがある（8.0 でディレクトリごとにも） (v2.2.0)
- pushKinds で、プッシュ通知を送る場面（完了・許可待ち）を選べる (v2.0.0)
- スマホで見ているセッションのディレクトリに、新しいターミナルを起動できる (v2.0.0)
- 自分で決めた定型文のチップをスマホの入力欄に入れられる (v2.0.0)
- GitHub のリポジトリなら、スマホのセッション画面から GitHub へ飛べる (v2.0.0)
- ツールバーにスマホとの接続状態（Online / Reconnecting / Offline）と原因を出す (v1.12.0)
- スマホから動いているターミナルに入力できる (v1.5.0)
- エージェントが提案した次のプロンプトをスマホでタップして送れる (v1.5.0)
- スマホでホストのターミナル画面を見られる（1.5 で自動更新、4.1.1 で300行の履歴） (v1.4.0)
- Web Push で通知する（1.0 で毎ターン、1.5 で許可待ちと返答本文も） (v0.9.2)
- スマホからスキル一覧・フィードを見て、会話を始められる（オフライン中は送信を待つ） (v0.7.0)
