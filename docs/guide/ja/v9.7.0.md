# 9.7.0 — 上限のトークンがいつ戻るか分かり、JingleScript が譜面をファイルから読める

**9.7.0（2026-10-10 リリース）時点のスナップショットです。** アプリが変わればこのページは古くなります。それは
想定どおりで、最新の説明は各節がリンクしているガイドにあります。

## 新機能

### 「トークンの使用量」画面に、上限のトークンが戻る日時が出る

[トークンのローテーション](token-rotation.html)を使っている場合の話です。**その他の機能 -> トークンの使用量**を開いてください。
使用量の上限に達したトークンは、これまで「上限に達しています。リセットされるまで選ばれません。」とだけ出て、いつ戻るのかが分かりませんでした。
今は、枠ごとに 1 行が加わります
([#2977](https://github.com/receptron/mulmoterminal/pull/2977))。

- `5 時間枠: 10/10 18:00 ごろにリセット（最後に確認した値）`
- `週の枠: 10/12 15:00 ごろにリセット（最後に確認した値）`

日時は画面の言語の書式で出ます。各枠が**最後に報告した**リセット時刻なので、そのトークンが最後に応答した時点の情報です。
すでに過ぎた時刻は出しません。Claude Code はどちらの枠で止まったかを教えてくれないため、両方の枠を並べます。
一度も測れていないトークンは、これまでどおり文だけが出ます。

### JingleScript が譜面をファイルから読める

JingleScript の譜面を依頼文に貼り付けなくても、`.json` ファイルに置いたものをエージェントにチェックさせたり、再生させたりできます
([#2979](https://github.com/receptron/mulmoterminal/pull/2979))。パスを渡してください。相対パスは、そのセッションのフォルダの中のファイルを指します。
読めるのは `.json` だけです。プレイヤーには**MIDI をダウンロード**するリンクも付きました。設定は要りません。

## 画面の変化

- **「トークンの使用量」画面の上限の行に、上で説明したリセットの行が加わります。**
- **JingleScript のプレイヤーに、MIDI のダウンロードのリンクが付きます。**

## 見えない変化

- **`mulmocast` は 2.19.0 になりました。** MulmoCast の台本で、ビートの中に効果音を置く `beat.soundEffects` が使え、
  効果音の元に JingleScript の譜面も指定できます。Gemini の動画モデルの既定は `gemini-omni-1.1-flash` になりました。Veo 3.1 のプレビュー版が
  2026-10-22 に終了するためで、それを指定した台本には、置き換え先を示すエラーが出ます
  ([#2979](https://github.com/receptron/mulmoterminal/pull/2979))。
- **パッケージを更新しました。** アイコンフォントの `material-symbols` も含みます
  ([#2978](https://github.com/receptron/mulmoterminal/pull/2978)、[#2980](https://github.com/receptron/mulmoterminal/pull/2980)、[#2982](https://github.com/receptron/mulmoterminal/pull/2982))。アイコンの見た目は変わりません。
- **ガイドを整えました。** 新しい冒頭のページ、アプリに合わせた各ページの修正、崩れていた表の修正です
  ([#2965](https://github.com/receptron/mulmoterminal/pull/2965)、[#2967](https://github.com/receptron/mulmoterminal/pull/2967)、[#2969](https://github.com/receptron/mulmoterminal/pull/2969)、[#2971](https://github.com/receptron/mulmoterminal/pull/2971)、[#2972](https://github.com/receptron/mulmoterminal/pull/2972)、[#2973](https://github.com/receptron/mulmoterminal/pull/2973)、[#2974](https://github.com/receptron/mulmoterminal/pull/2974))。

詳しくは: [トークンのローテーション](token-rotation.html)、[機能一覧](feature-list.html)。

**入っているか確かめるには:** トークンのローテーションを使っていて、上限に達したトークンがあれば、
「その他の機能 -> トークンの使用量」の上限の文の下に「ごろにリセット」の行が出ます。
