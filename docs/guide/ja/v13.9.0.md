# 13.9.0 — 自分で打つ git が MulmoTerminal とぶつからなくなる

**13.9.0（2026-11-27 リリース）時点のスナップショットです。** アプリが進むにつれて古くなります。
それは想定どおりで、最新の内容は各節からリンクしているガイドにあります。

更新:

```bash
npx mulmoterminal@latest
```

設定は要りません。

## 新機能

このリリースで新しく入れるものはありません。

## 画面の変化

- **What's new の画面がお礼を伝えます。** 更新のあとに開くこの画面が、「MulmoTerminal 13.9.0 が出ました！」で
  始まり、その下に短いメッセージを添えるようになりました。
  使ってくれていることへのお礼と、役に立っているなら友人や同僚に教えたり、投稿やブログで
  紹介してもらえるとうれしい、という内容です
  （[#3566](https://github.com/receptron/mulmoterminal/pull/3566)）。いまこのページを読んでいる
  画面がそれです。

## 見えない変化

- **自分で打つ git が `index.lock: File exists` で失敗しなくなりました。** MulmoTerminal は開いている
  フォルダの git の状態（未コミットの変更の数や、ファイルツリーの色分け）を裏で調べています。
  この確認が一瞬 `.git/index.lock` を握ることがあり、ちょうどそのとき自分やエージェントが打った
  `git add`・`git commit`・`git switch`・`git merge` が
  `fatal: Unable to create '…/.git/index.lock': File exists` で失敗していました（1秒後にはロックは
  消えています）。裏の確認はこのロックを取らなくなりました
  （[#3564](https://github.com/receptron/mulmoterminal/pull/3564)、
  [#3556](https://github.com/receptron/mulmoterminal/issues/3556) の対応）。やることはありません。
  直ったことの確かめ方: セルで開いているフォルダで、コミットした直後に `git add` や `git switch` を
  するスクリプトが、ときどき失敗することがなくなります。
- **ターミナルでクリックしたファイルまでファイルツリーが開きます。** ファイルペインを閉じた状態で
  セルの出力中のパスをクリックすると、ファイルは開くのにツリーは閉じたままで、どこにあるファイルか
  見えませんでした。今はそのファイルまでフォルダを開き、そこへスクロールします
  （[#3563](https://github.com/receptron/mulmoterminal/pull/3563)）。直ったことの確かめ方:
  ファイルペインを閉じ、セルに出たファイルパスをクリックすると、ツリーがそのファイルまで開いた状態で
  見えます。詳しくは [機能一覧](features.html)。
- **Antigravity の計画を承認すると、それが別のターンになります。** Antigravity 自身の画面で計画を
  承認すると、会話の表示はそのあとの作業をすべて「計画を頼んだターン」にまとめてしまい、
  ターン終了の通知にも指示が入っていませんでした。今は承認から新しいターンが始まります
  （[#3560](https://github.com/receptron/mulmoterminal/pull/3560)）。詳しくは
  [エージェント](agents.html#at-a-glance)。
- **Claude の会話の古いページも、正しくターンに分かれます。** 13.8.2 でスキルの呼び出しがターンを
  分けないようにしました。それでも、会話の表示が古いページを読み込むときや、ヘッダーが最新の指示を
  読むときに、読み始めがちょうどスキルの本文だと同じ取り違えが起きていました。これも直りました
  （[#3554](https://github.com/receptron/mulmoterminal/pull/3554)）。やることはありません。
