# 13.8.2 — バックグラウンドに移した会話も追い続ける

**13.8.2（2026-11-26 リリース）時点のスナップショットです。** アプリが進むにつれて古くなります。
それは想定どおりで、最新の内容は各節からリンクしているガイドにあります。

更新:

```bash
npx mulmoterminal@latest
```

設定は要りません。直しのリリースです。

## 新機能

新しく入れるものはありません。今あるものの直しです。

## 画面の変化

- **スキルの評価が、改善案が本当に良いかを示します。** これまで改善案の欄は「今 X → 改善案 Y」と出し、
  Y が大きければ **採用する** を勧めていました。今は要約と同じ決まりで二つを比べ、回ごとのばらつきを超えて
  多く通ったか、減ったか、ばらつきの範囲に収まっているか（回数が足りないときはそう書きます）を文で示します。
  改善案で通る回数が減った課題も挙げ、次の一手が採用を勧めるのは多く通ったときだけです。**採用する** の
  ボタン自体はこれまでどおりあります（[#3531](https://github.com/receptron/mulmoterminal/pull/3531)）。
- **スキルがあってもなくても通る課題を挙げます。** どちらでも毎回通る課題では、スキルの効き目は
  わかりません。結果にそうした課題を挙げ、課題ごとの表に *（どちらでも通る）* と印を付けます。課題を
  作るときも、スキルなしのエージェントが間違えそうな課題を求めるようにしました
  （[#3532](https://github.com/receptron/mulmoterminal/pull/3532)）。
- **HTML の計画スキルは、Canvas が無いと頼んできます。** Canvas を入れていないプロジェクトのセルでは、
  `mulmoterminal-html-plan` が案を作る前に止まり、ランチャの MCP トグルでそのフォルダの Canvas を入れて
  から、セルのメニューで **エージェントを再起動** を選ぶよう伝えます。ページがペインに出ない回り道は
  しなくなりました（[#3542](https://github.com/receptron/mulmoterminal/pull/3542)）。

詳しく: [スキルは効いているか](skill-eval.html#result)、[機能一覧](features.html)

## 見えない変化

- **← でバックグラウンドに移した Claude の会話も追い続けます。** Claude Code はその会話を新しい
  セッション ID で続けます。これまでセルの作業の履歴と会話ペインは、ターミナルが動き続けていても ← を
  押したところで止まっていました。今は新しい ID に付いていき、あとでセルを開き直したときもその会話を
  再開します（[#3540](https://github.com/receptron/mulmoterminal/pull/3540)）。入ったかどうかは、← を
  押してからもう一つ指示を出すと、会話ペインにそのターンが出ることでわかります。
  [よくある質問 — 開き直したセルで、最後の会話が消えていました](faq.html#cell-reopened) も見てください。
- **Claude Code の予備のプロセスで、プロンプトペインがずれなくなりました。** ← を押すと、Claude Code は
  裏で予備のプロセスも立ち上げます。その起動の知らせで、プロンプトペインが一時、関係のない会話を
  読むことがありました（[#3545](https://github.com/receptron/mulmoterminal/pull/3545)）。することは
  ありません。
- **スキルを呼んでもターンが分かれなくなりました。** Skill ツールを呼ぶと、Claude Code はスキルの本文を
  あなたが打ったかのように会話に書き込みます。貼った画像の注記も同じです。会話の表示はそれを新しい
  プロンプトとして出し、ヘッダーは最新のプロンプトとして扱い、そのターンのツールの一覧は空になって
  いました。今はそれを、属しているターンの一部として読みます
  （[#3550](https://github.com/receptron/mulmoterminal/pull/3550)）。入ったかどうかは、スキルを
  動かすと、会話の表示にあなたのプロンプトとスキルのツールが一つのターンとして出ることでわかります。
- **開発する人向け:** 重複を探す仕組みが見つけたコードを、それぞれ一か所にまとめました。copilot・
  Antigravity・Grok の最後のターンの読み取り、会話の表示のツール呼び出しの行、ライブラリの二つの
  route、ライブラリの戻るボタンです（[#3548](https://github.com/receptron/mulmoterminal/pull/3548)）。
  することはありません。
