# 1.9.1：Windows でセッションが起動、ターミナルのリンクが復活

## 困ったときの `/mulmoterminal-bug-report`

**新しく使えるようになったもの**です。「なんか変」と思ったら、どのターミナルでもこう打ってください。

```
/mulmoterminal-bug-report
```

**目的は issue を立てることではなく、あなたを前に進めることです。** 症状を1つずつ聞き、**実際の設定・スキーマ・バージョンを読んで**仕様や設定で説明がつかないか確かめ、既知の issue を検索します（直っていて古いバージョンを使っているだけなら、報告ではなく更新の案内で終わります）。残ったものだけ報告用にまとめ、環境情報は自動収集・**キーはマスク**、投稿前に全文プレビューと同意を求めます。

## Windows でセッションが起動しなくなっていた問題

すべての `claude` セッションが `File not found:` （コロンの後は空）で失敗していました。同じホストで Codex は動くという不可解な状況です。原因は node-pty が Windows のパス探索で**ファイル名を完全一致でしか比較せず、拡張子を補わない**ことでした。公式インストーラが置く `claude.exe` に、素の `claude` では届きません。

**設定は不要です。** 上げれば直ります。`npm i -g` で入れた場合は 1.9.2 も必要です。

## ターミナル内のリンクがクリックできます

Claude のステータスラインの `PR #NNNN` などが、クリックしても何も起きませんでした。原因はフロントエンドではなく **tmux が OSC 8 を落としていた**ことでした。設定を書き込むようにしたので、**クリックで直接開きます**（確認ダイアログも出ません）。
