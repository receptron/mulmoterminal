# 1.9.0：スマホにセッションの素性が届くように
{: .no_toc }

**2026-07-24 時点**のスナップショットです。

**設定は不要です。**

---

## スマホの画面にディレクトリ・ブランチ・要約が出ます

スマホでターミナルを見たとき、これまでは**画面の中身しか届いていませんでした**。作業ディレクトリ、git ブランチ、AI が付けたセッションの要約、直近のプロンプトが一緒に届くようになり、グリッドのセルヘッダーと同じ情報が見られます。

ホストが答えられない項目は**キーごと省かれます**。空欄で送ると「ブランチが無い」と読めてしまい、「分からない」と区別がつかないためです。ホスト再起動をまたいだセッションは PTY が残っていないので、これまでどおり画面だけが届きます。

→ [スマホから使う](phone.html)

## グリッドのボタンの見た目が揃いました

ランチャーセルとコマンドセルの ⤢ / ✕ が、**ブラウザ既定の灰色の箱**として表示されていました。原因は CSS でもテーマでもなく、`CellChromeButtons` が**フラグメントルート**（`<button>` が2つ）で、Vue はスコープ ID を単一のルート要素にしか渡さないため、共有していたスコープ付き CSS がどの要素にも当たっていなかったことです。

この件を受けて、セルの共通スタイルは **Tailwind ユーティリティ**に移しました。ユーティリティはグローバルなので、フラグメントルートのコンポーネントにも構造的に届きます。
