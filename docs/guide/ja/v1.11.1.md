# 1.11.1：Windows の npm-global 版で起動するように
{: .no_toc }

**2026-07-26 時点**のスナップショットです。

**設定は不要です。** Windows 以外の方には影響がありません。

---

## 直ったこと

`npm i -g` で入れた Claude Code を使う Windows で、**セッションが起動した瞬間に落ちて**いました。エラーはこう出ます。

```
Error: Settings file not found: {"hooks:{UserPromptSubmit:[{hooks:[{type:command,command:curl
```

`--settings` に渡す JSON から**クォートがほぼ全部消えて**いました。原因は受け取る側で、`""` を1つのリテラルクォートとして解釈するのは Microsoft の C ランタイムの拡張であり、`claude.exe` はそれを実装していないネイティブバイナリだったためです。

**JSON をファイルに書いてパスだけを渡す**ようにしたので、claude に渡る引数にはクォートが1つも含まれなくなりました。POSIX 側は従来どおりです。

## 確認方法

Windows でセッションを起動して、そのまま続けば直っています。

診断の経緯も記録に残しています。**最初の診断は間違っていました。** CI テストが通っていたのは、テストの子プロセスが Windows で最も寛容な argv パーサである `node.exe` だったからです。自分の身代わりが本物と同じ挙動をするか、という仮定だけを検証していませんでした。
