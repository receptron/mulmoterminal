# 9.8.0 — ヘルプ係が加わり、Ctrl+B がエージェントへ届く

**9.8.0（2026-10-10 リリース）時点のスナップショットです。** アプリが変わればこのページは古くなります。それは
想定どおりで、最新の説明は各節がリンクしているガイドにあります。

## 新機能

### MulmoTerminal のことをヘルプ係に聞く

ツールバーの歯車の隣に、**ヘルプのアイコン**が加わりました
([#2987](https://github.com/receptron/mulmoterminal/pull/2987))。押すと、ワークスペースに新しいターミナルが開き、ヘルプ用のエージェントが
すでに動いています。ふだんの言葉で聞いてください。MulmoTerminal に何ができるか、画面のこの部分はどう動くか、どう設定するか、
いま使っている版と最新版で何が新しいか、などです。

- 答えは、**お使いの版に同梱された**ガイド・変更履歴・ソースをもとに、どこで確かめたかを添えて返します。お使いの版にない機能を説明することは
  ありません。
- 読むだけで、何も書き換えません。そのため、押しても確認は出ません。設定の変更やバグの報告を頼むと、それぞれの担当へ案内します。
- **Settings -> Help** の、ガイドへのリンクの下にも同じボタンがあります。
- 画面に出ているプロジェクトやコレクションにかかわらず、いつもワークスペースで開きます。聞くのはアプリのことで、そのプロジェクトのことでは
  ないからです。

設定は要りません。

### Ctrl+B がエージェントへ届く：tmux の prefix を無効に

各セルは、再起動してもセッションが残るように、専用の tmux の中で動いています。tmux は **prefix キー**（標準は **Ctrl+B**）を待ち受け、その次の
キーを tmux のコマンドとして読みます。ところが Ctrl+B は、シェルでも Claude Code の入力欄でも macOS のテキスト入力でも「1文字左」です。
セルでは、1回目の Ctrl+B が無視されたように見え、次に押したキー（`c`、`%`、`d`）がエージェントに届かず tmux のコマンドになっていました
([#2985](https://github.com/receptron/mulmoterminal/pull/2985))。

MulmoTerminal はこの prefix を使わないので、**既定で無効**にしました。すべてのキーがエージェントへ届きます。何もする必要はありません。

自分でセッションに接続して（`tmux -L mulmoterminal attach`）`Ctrl+B d`（デタッチ）などの tmux のキー操作を使いたい場合は、prefix を戻します。

1. **Settings -> Terminal keys** の **tmux の prefix キー**で、`Ctrl+B`（tmux 本来の既定）か `Ctrl+]` を選びます。
2. または `~/.mulmoterminal/config.json` に `{ "tmuxPrefix": "C-b" }` と書きます。ほかの Control キー（`C-a`〜`C-z`、`C-Space`、`C-]`、`C-_`、
   `C-^`、`C-@`）も使えます。それ以外の値は「無効」に戻ります。
3. 保存するとすぐ反映され、すでに動いている tmux サーバーにも効きます。再起動は要りません。

マウスのホイールによる履歴のスクロールは、どちらの設定でも使えます。詳しくは: [設定](config.html#tmux-prefix)。

## 画面の変化

- **ツールバーにヘルプのアイコン**が出て、Settings にも Help のボタンが付きます。
- **Settings -> Terminal keys に「tmux の prefix キー」のドロップダウン**が加わります。
- **ファイルペインのヘッダーが、狭いときに折り返します。**閉じるボタンがペインの外に出なくなりました
  ([#2988](https://github.com/receptron/mulmoterminal/pull/2988))。これまでは、Markdown を開いた状態で分割が狭いと、閉じるボタンを含む最後のほうの
  ボタンがウィンドウの外へはみ出していました。隠れるものも動くものもなく、ボタンが 2 行目に続くだけです。
- **ファイルペインを開いたまま始めたセッションが、正しい横幅で始まります。**これまでは、ペインの横にあったときの幅で始まり、何かが
  大きさを変えるまで直りませんでした
  ([#2989](https://github.com/receptron/mulmoterminal/pull/2989))。

## 見えない変化

- **npm のパッケージに、ガイドの全ページが入りました。**変更履歴と `docs/facts.json` も入るので、ヘルプ係はオフラインでも動き、入っている版と
  一致します ([#2987](https://github.com/receptron/mulmoterminal/pull/2987))。パッケージは数メガバイト大きくなります。
- **動いている tmux サーバーが、保存した設定に従います。**アプリより長く生きている tmux サーバーにも反映され、読み込む設定ファイルは
  途中の状態を読まれない方法で書かれ、以前の実行が残した prefix の割り当ては外されます
  ([#2985](https://github.com/receptron/mulmoterminal/pull/2985))。

詳しくは: [設定](config.html)、[機能一覧](feature-list.html)。

**入っているか確かめるには:** ツールバーの歯車の隣にヘルプのアイコンがあり、セルで Ctrl+B を 1 回押すとカーソルが 1 文字左へ動きます。
