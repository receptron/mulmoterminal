# 12.0.1 — 全角コロンの直後のパスがリンクになる

**12.0.1 時点（2026-11-05 リリース）のスナップショットです。** アプリが変わるにつれて古くなります。
それは想定どおりで、最新の説明は各節からリンクしているガイドにあります。

**設定は要りません。** 上げれば直ります:

```bash
npx mulmoterminal@latest
```

## 新機能

この版にはありません。

## 画面の変化

### 「：」の直後のパスが、パスだけでリンクになる

ターミナルに出たファイルパスは、クリックできるリンクになります
（[クリックできるファイルパス](https://receptron.github.io/mulmoterminal/guide/ja/features.html)）。
エージェントが日本語で書き、全角コロンの直後に空白なしでパスを置くと —

```
できたこと：D:\Users\me\work\notes.md の該当行に追記しました。
```

— リンクがおかしくなっていました（[#3269](https://github.com/receptron/mulmoterminal/pull/3269)、
[#3268](https://github.com/receptron/mulmoterminal/issues/3268) の対応）:

- `できたこと：src/a.md` のような `/` 区切りのパスは、**前の日本語ごと**リンクになり、クリックすると
  存在しないファイルを開こうとしていました
- `できたこと：D:\x\a.md` のような Windows のドライブ付きのパスは、**リンクになりません**でした

半角の `:` の後に空白がある場合は、元から問題ありません。今回、全角の `：；，！？` も `、` `。` と同じく
パスの区切りとして扱うようにしたので、下線が付くのはパスだけになります。

副作用が 1 つあります。**ファイル名そのもの**にこの 5 文字のどれかを含むと、その文字で切れるように
なります。`、` `。` や全角の括弧で既にしているのと同じ割り切りです。

**修正が入ったかどうかの見分け方:** 上のような行をセルに出して（たとえば `docs/plan.md` がある
ディレクトリで `echo 'できたこと：docs/plan.md を見た'`）、パスにマウスを乗せます。12.0.1 からは
`docs/plan.md` だけに下線が付きます。以前は `で` から下線が付いていました。

## 見えない変化

Files ペインの読み込みと変更に答える 2 つの経路で、「このパスはフォルダの内側か」の確認を 1 つの処理に
まとめました（[#3267](https://github.com/receptron/mulmoterminal/pull/3267)）。答えは以前と同じです。
なくなったフォルダは「見つからない」、フォルダの外へ出るパスは拒否、のままです。何もする必要はありません。
